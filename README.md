# Smart Learn Hub

PROJECT: MY LIBRARY — КИТОБХОНАИ МАН

Improve my existing website and turn it into a powerful, modern, intelligent educational platform for students in Tajikistan. The website name must be “КИТОБХОНАИ МАН”.

IMPORTANT: Do not rebuild the project from scratch if it already has working features. First inspect the existing project, understand its structure, and improve it while preserving all existing functionality.

1. LANGUAGE

- The entire website interface must be in Tajik.

- All buttons, menus, headings, instructions, books, educational materials, questions, answers, quizzes, and AI responses should be in Tajik.

- Use clear, correct, natural Tajik Cyrillic.

- The website instructions in this prompt are in English, but the actual website must be in Tajik.

2. HOMEPAGE

Create a beautiful, premium-quality homepage with the main heading:

“Хуш омадед ба саволнома ва китобхона”

The homepage must contain three main sections with attractive interactive buttons:

1. Кластер

2. Китобхона

3. Зеҳни сунъӣ (ИИ)

Add a modern logo, smooth animations, attractive backgrounds, elegant cards, clear navigation, and a professional educational design.

3. CLUSTER SECTION — TAJIKISTAN NATIONAL TESTING CENTER

Create a complete cluster preparation section based on the six clusters of Tajikistan's National Testing Center.

Requirements:

- Organize subjects according to the official cluster structure.

- Provide subject categories, practice tests, multiple-choice questions, answer options, and correct answers.

- Display explanations for answers when appropriate.

- Include a quiz timer, progress indicator, score calculation, and final results.

- Allow students to practice questions by subject and difficulty.

- Include search and filtering features.

- Use verified official sources when presenting official information or past exam questions.

- Clearly distinguish authentic official questions from newly generated practice questions.

- Never invent questions and label them as official NTC questions.

- If official materials are unavailable, provide original practice questions and clearly label them as practice materials.

4. LIBRARY SECTION — A LARGE EDUCATIONAL LIBRARY

Create a large, well-organized digital library with as many useful educational resources as can be lawfully and reliably added.

Include categories such as:

- Mathematics

- Physics

- Chemistry

- Biology

- Geography

- History of Tajikistan

- World History

- Tajik Language

- Tajik Literature

- Russian Language

- English Language

- Computer Science

- Programming

- Information Technology

- Dictionaries

- Formulas and reference materials

- School textbooks

- Exam preparation materials

When a student selects a category, show the available books, learning resources, questions, and answers for that subject.

Library features:

- Search books and learning materials.

- Organize content by subject, grade, and topic where applicable.

- Provide readable content pages.

- Add bookmarks and saved materials.

- Make resources easy to access on mobile phones.

- Include downloadable resources only when the files are actually available and distribution is permitted.

- Do not display fake books, broken download buttons, or nonexistent resources.

- Make it easy for administrators to add new books and educational materials.

5. AI EDUCATIONAL ASSISTANT

Create a powerful AI assistant that can help students learn different subjects.

The AI should be able to:

- Answer educational questions in Tajik.

- Explain mathematics step by step.

- Help solve physics and chemistry problems.

- Explain biology, geography, and history.

- Help with Tajik, Russian, and English languages.

- Teach programming and information technology.

- Explain difficult topics in simple language.

- Generate original practice questions and quizzes.

- Check student answers and explain mistakes.

- Create summaries, revision notes, and study guides.

- Adapt explanations to the student's learning level.

The AI interface should include a message input field, a send button, a clear conversation area, and a convenient mobile-friendly design.

Technical requirement: Integrate a real AI model through a secure backend. Never expose API keys in frontend code. If an API key or external service is required, clearly explain what must be configured. Do not pretend the AI is working if the integration is incomplete.

6. AUTOMATIC CONTENT EXPANSION

Build a system that allows the educational content to grow over time.

Requirements:

- Allow the AI to generate new, original practice questions and educational materials.

- Organize generated content by subject, topic, difficulty, and grade where appropriate.

- Detect and reduce duplicate questions.

- Save approved generated questions and materials in the database.

- Allow administrators to review, edit, approve, or delete generated content.

- Provide a way to generate additional questions whenever needed.

- Support bulk importing of questions and educational materials.

- Design the database to handle tens of thousands of questions and many educational resources.

- If scheduled background generation is supported by the available backend, allow new practice content to be generated automatically.

- Do not claim that content is being generated automatically unless the required backend functionality is implemented.

- Clearly label AI-generated materials as practice content rather than official examination questions.

7. PREMIUM WEBSITE DESIGN

Make the website visually impressive, modern, and professional.

Design requirements:

- Premium educational platform aesthetic.

- Modern gradients and elegant color combinations.

- Beautiful cards and buttons.

- Smooth transitions and subtle animations.

- Attractive hover effects on supported devices.

- Clear typography and readable Tajik text.

- Well-organized spacing and layouts.

- A consistent design across every page.

- A professional homepage that immediately creates a strong impression.

- Avoid excessive animations, clutter, and effects that make the website slow.

The website must work properly on:

- Android phones

- iPhones

- Tablets

- Laptops

- Desktop computers

Use a responsive layout for all screen sizes.

8. ADMIN DASHBOARD

Create a secure administration dashboard that allows authorized administrators to:

- Add, edit, and delete books.

- Create and manage subjects and categories.

- Add, edit, and delete questions.

- Manage answers and explanations.

- Import questions in bulk.

- Review AI-generated materials.

- Approve or reject generated content.

- Manage educational resources.

- Search and filter the content database.

- View basic usage statistics when supported.

Protect administrative functions with proper authentication and authorization. Regular users must not be able to access or modify administrative data.

9. DATABASE AND FUNCTIONALITY

Connect the website to a real database when required.

The database should support:

- Subjects and categories.

- Books and learning resources.

- Questions and answer options.

- Correct answers and explanations.

- Practice tests and results.

- AI-generated educational content.

- Saved materials and bookmarks.

- User accounts and permissions where needed.

Important:

- All buttons must perform their intended actions.

- Search must return actual matching content.

- Quiz scores must be calculated correctly.

- Questions and answers must be saved persistently.

- Forms must validate user input.

- Loading, success, empty, and error states must be handled properly.

- Do not use fake functionality or placeholder buttons that appear to work but do nothing.

- Use secure database access rules and protect private information.

10. PERFORMANCE AND QUALITY

Make the website fast, reliable, and easy to use.

Requirements:

- Optimize images and assets.

- Avoid unnecessary dependencies.

- Use reusable components.

- Keep the code organized and maintainable.

- Prevent duplicate database records where possible.

- Handle errors gracefully.

- Make navigation simple and intuitive.

- Ensure that the website remains usable on slower mobile connections.

11. FINAL IMPLEMENTATION INSTRUCTIONS

Before making changes:

1. Inspect the existing website and its code.

2. Identify the features that already work.

3. Preserve existing functionality.

4. Improve the design and implement the requested features.

5. Connect the necessary database and AI services where available.

6. Test the main user flows and fix any errors.

7. Ensure the website interface remains in Tajik.

Do not simply provide recommendations or a description of what should be built. Implement as much as possible directly in the existing project.

If an external API, database configuration, authentication provider, official data source, or other credential is required, clearly identify the missing requirement instead of pretending it has already been configured.
